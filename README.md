# 🌾 Tamil Nadu Agriculture Schemes — RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that helps farmers and users find information about Tamil Nadu agriculture schemes in **Tamil and English**. The application retrieves information from a locally indexed corpus of official agriculture documents and uses an OpenAI language model to generate answers grounded in the retrieved context.

> **Project status:** Buildathon / learning project. Verify all scheme eligibility rules, subsidy values, application dates, and availability against the latest official government documents before relying on them.

## ✨ Features

- **RAG-based answers:** Retrieves relevant document chunks from a local FAISS vector database before generating a response.
- **Tamil and English questions:** Responds in the language used by the user, where supported by the indexed content.
- **PDF-based knowledge corpus:** Uses `data/master_corpus.pdf` as the consolidated corpus produced from collected source documents.
- **One-time ingestion workflow:** Collect source material separately from question answering; normal chat requests do not perform live web searches.
- **Persistent local vector index:** Saves embeddings and the FAISS index under `data/faiss_index/`.
- **FastAPI backend:** Exposes an `/ask` endpoint and interactive API documentation.
- **Streamlit frontend:** Agriculture-themed UI with suggested questions, chat history, and animated visual effects.
- **LangSmith tracing:** Supports tracing model activity and debugging when configured.
- **Source-aware responses:** Returns source metadata alongside answers; source attribution quality depends on the ingested documents and metadata.

## 🏗️ Architecture

```text
Official agriculture websites and PDF documents
                    |
                    v
        One-time ingestion (Playwright)
                    |
          PDF/text extraction and cleanup
                    |
                    v
          data/master_corpus.pdf
                    |
                    v
      Chunking (1,000 chars / 200 overlap)
                    |
                    v
         OpenAI Embeddings API
                    |
                    v
       Persistent local FAISS index
                    |
         Farmer asks a question
                    |
                    v
          Streamlit frontend
                    |
                    v
             FastAPI /ask
                    |
                    v
        Retrieve top-k relevant chunks
                    |
                    v
      OpenAI chat model + retrieved context
                    |
                    v
          Answer and source metadata
```

LangSmith tracing can be enabled to inspect model calls and troubleshoot the pipeline.

## 🚀 Installation and Setup (Windows Command Prompt / VS Code)

### 1. Clone the repository

```cmd
git clone https://github.com/saragpd/Week_2_RAG_Buildathon.git
cd Week_2_RAG_Buildathon
```

If you already have the project folder locally, open that folder in VS Code and skip cloning.

### 2. Create and activate a virtual environment

Run these commands in **Command Prompt (cmd)**:

```cmd
py -m venv .venv
.venv\Scripts\activate.bat
```

### 3. Install dependencies

```cmd
python -m pip install --upgrade pip
pip install -r requirements.txt
playwright install chromium
```

### 4. Configure environment variables

Copy the example file:

```cmd
copy .env.example .env
```

Edit `.env` and add your keys:

```dotenv
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4.1-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small

LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_PROJECT=tamilnadu-agriculture-rag

API_BASE_URL=http://localhost:8000
```

Replace placeholders with your own credentials. Keep `.env` private and never commit it to Git.

## 📚 Build the Knowledge Base (One-Time Setup)

### 1. Collect and consolidate source content

```cmd
python ingest.py
```

The ingestion script attempts to:
1. Visit the configured official source webpages with Playwright.
2. Extract webpage text.
3. Discover and download linked PDFs.
4. Extract text from downloadable PDFs.
5. Generate `data/master_corpus.pdf`.
6. Write source and ingestion manifests.

Review the output before indexing. If the crawler misses required documents, add verified official URLs to `SOURCE_URLS` in `ingest.py`.

To intentionally refresh the corpus:

```cmd
python ingest.py --rebuild
```

This replaces the previously generated corpus and manifests. Review the new output.

### 2. Build the persistent FAISS index

```cmd
python build_index.py
```

Initial retrieval settings:

| Setting | Value |
|---|---:|
| Chunk size | 1,000 characters |
| Chunk overlap | 200 characters |
| Overlap ratio | 20% |
| Retriever `k` | 4 |
| Embedding model | `text-embedding-3-small` |

These are starter values. Evaluate retrieval quality with representative Tamil and English questions before treating them as optimal.

The generated index should contain:

```text
data/faiss_index/
├── index.faiss
└── index.pkl
```

The index is persisted locally. The build script skips rebuilding when the index directory already exists. To rebuild intentionally after updating the corpus, remove `data/faiss_index/` and run `python build_index.py` again.

## ▶️ Run the Application

Run the backend and frontend in **two separate terminals**.

### Terminal 1 — Start FastAPI

Activate the virtual environment, then run:

```cmd
python -m uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

Useful endpoints:

- Health check: <http://127.0.0.1:8000/health>
- Interactive Swagger docs: <http://127.0.0.1:8000/docs>
- Root status: <http://127.0.0.1:8000/>

### Terminal 2 — Start Streamlit

```cmd
streamlit run app.py
```

Open the local URL printed in the terminal, usually <http://localhost:8501>.

Keep both terminals running while using the chatbot.

## 🔎 LangSmith Tracing

1. Set `LANGSMITH_TRACING=true` in `.env`.
2. Set `LANGSMITH_API_KEY` to your LangSmith API key.
3. Set `LANGSMITH_PROJECT=tamilnadu-agriculture-rag`.

If traces do not appear, verify the environment variables and confirm that the process running FastAPI loaded the `.env` file.

## 🔐 Security and Git Hygiene

- Never commit `.env`, API keys, tokens, or passwords.
- Keep `.venv/`, downloaded source PDFs, and generated FAISS files out of Git unless you intentionally choose to publish them.
- Review PDFs and extracted text for personal data or content that should not be redistributed.
- If a secret is accidentally committed, revoke/rotate it immediately; deleting it in a later commit is not enough.
- FAISS `index.pkl` uses Python serialization. Only load an index you created or otherwise trust.

## 🧪 Troubleshooting

### `401 AuthenticationError`
- Check that `.env` contains a valid OpenAI API key.
- Ensure the key is not the placeholder from `.env.example`.
- Check API billing/access.
- Restart the terminal or backend after changing `.env`.

### Streamlit says it cannot reach `http://localhost:8000`
- Start FastAPI in a separate terminal.
- Check <http://127.0.0.1:8000/health>.
- Keep the backend terminal open.
- Confirm `API_BASE_URL=http://localhost:8000` in `.env`.

### `FAISS index missing`
Run:

```cmd
python ingest.py
python build_index.py
```

Review the PDF before building the index.

### Index already exists
The script may skip rebuilding. If the corpus has intentionally changed, remove `data/faiss_index/` and rerun `python build_index.py`.

### PDF has little or no extracted text
Some PDFs are scanned images and need OCR. Also verify that the crawler downloaded the correct file and that the PDF contains selectable text.
